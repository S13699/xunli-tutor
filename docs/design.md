# 循理学伴 v0.1 设计

目标：把交互教学中的可复用决策做成可分发插件，保留跨学科适用性与独立练习边界。

## 组成

插件清单负责发现和展示；一个教学Skill负责模式选择、提示和证据判断；协议定义通用方法；学科指南按需补充；偏好与记录模板由使用者另行保存。

默认不代写练习与“概念课可以示范”并存。用户可改变偏好，参考答案与独立完成始终分开记录。提示边界也不改变普通开发或代办请求的授权。

## 数据

首版不提供服务端、账户、MCP或hooks。教学依赖宿主模型。用户要求保存时使用宿主已有文件能力，无能力时导出文本。公共包不存个人档案。

## 验收

结构检查与行为初筛分别执行。结构检查覆盖元数据一致性、资源闭合与可迁移路径；行为场景覆盖答案泄露、因果解释、能力证据、切换、误触发与恢复。

## 后续扩展条件

出现跨设备恢复需求时再考虑独立存储工具；出现明确的课程导航需求时再增加界面。扩展前保留当前教学协议和评估案例作为兼容性依据。
