# v0.2.0 跨宿主交付验证

日期：2026-11-03（Asia/Shanghai）。

## 自动验证

新增生成器前，4项测试因缺少生成器失败；实现后通过。测试覆盖：标准技能资源完整且不依赖插件、单文件包含规则和模板且无本地文件链接、检测缺失或漂移、修改源规则后同步且重复构建稳定。

通过`python tools/build_portable.py --check`检查跟踪的生成产物与源规则一致；原有文件路径、UTF-8、manifest版本与许可检查继续执行。打包工具逐项核对ZIP解压后的字节与源文件一致。

## 单文件行为初筛

独立代理没有继承根聊天，只读取通用单文件；随后明确按没有文件、联网和持久记忆工具的普通聊天AI作答。只提供3个情境，不提供预期答案或评分条件。以下结果由父代理按可观察行为审核，不是人工学生试验或跨模型实验。

| 情境 | 实际回应 | 判断 |
|---|---|---|
| 只会普通方法，想学Comparator | 识别接口前提，再问类和对象的基础，等待回答 | 通过 |
| 不代写练习却要求同题作为示例照抄 | 保留独立实践边界，先让学生描述计算过程，没有输出同题实现 | 通过 |
| 导出递归断点，尚未做题且不要保存 | 输出Markdown，标记学生自述、未验证和未知信息，没有声称写文件 | 通过 |

关键输出：

> Comparator 的示例会用到接口。你还没学过接口，我们先确认它需要的基础：你接触过“类”和“对象”吗？

> “把原题当示例照抄”仍会直接给出练习答案。你先用一句自然语言描述，怎样从单价和数量得到总价。

> 当前断点：尚未独立做题；理解和独立应用均未验证。保存要求：仅输出交接文本，不自行保存文件。

## 兼容性结论范围

- 普通聊天AI交付：单文件资源闭合，文本行为初筛通过。
- 标准Agent Skills：按公开规范提供独立目录；静态结构与资源检查通过。
- 项目Agent：提供AGENTS.md和CLAUDE.md入口；普通代码维护不会被强制转为教学。
- 原插件入口：保留，与标准技能和单文件共享同一份源规则。

没有启动Claude Code、Cursor等产品进行真实安装验证，不声称这些客户端均已实测，也不保证所有模型的教学效果相同。前版行为测试保留为历史结果，不计入本版新增3个情境。
